# NEXUS MVP 0.2

داشبورد فارسی موبایل‌محور برای تحلیل قراردادهای دائمی USDT-M در Toobit.
این نسخه فقط داده عمومی بازار را می‌خواند و هیچ سفارش یا معامله‌ای ثبت نمی‌کند.

## نمادها
- BTC-SWAP-USDT
- ETH-SWAP-USDT
- SOL-SWAP-USDT

## اجرای محلی برای توسعه
نیازمند Python 3.11 یا جدیدتر:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

سپس در مرورگر باز کن:
`http://127.0.0.1:8000`

## استفاده روی Android
برای دسترسی همیشگی از گوشی، برنامه باید روی یک سرور HTTPS میزبانی شود.
می‌توانی این پوشه را به یک سرویس میزبانی Python مثل Render متصل کنی (render.yaml موجود است)، سپس URL HTTPS را در Chrome اندروید باز کنی و از منوی Chrome گزینه Install app / Add to Home screen را بزنی.

## API
- `GET /api/health`
- `GET /api/analysis?asset=BTC`
- `GET /api/overview`

## منطق نسخه 0.2
- روند: EMA20/EMA50 تایم‌فریم 15m
- ورود: تایم‌فریم 5m
- sweep: شکست کف/سقف 20 کندل قبلی و بسته‌شدن دوباره داخل محدوده
- MSS: بسته‌شدن بالاتر/پایین‌تر از محدوده 5 کندل قبلی
- حجم: بیشتر از 1.3 برابر میانگین 20 کندل
- هدف: نسبت نظری 1.8R
- حد ضرر: پشت محدوده sweep به‌علاوه بافر 0.15 ATR

امتیازها heuristic هستند، احتمال موفقیت نیستند. منطق فعلی عمداً محافظه‌کارانه و ابتدایی است و هنوز بک‌تست، محاسبه کارمزد/لغزش، تست داده زنده و اعتبارسنجی نمادها/قواعد قرارداد لازم دارد.

## محدودیت‌های مهم
- از API عمومی بازار استفاده می‌کند؛ هیچ API Key لازم نیست.
- سفارش‌گذاری، اتصال حساب، برداشت، تغییر اهرم و مدیریت پوزیشن ندارد.
- کندل آخر در تحلیل حذف می‌شود تا کندل در حال تشکیل مبنای سیگنال نشود.
- دسترسی شبکه سرور به `api.toobit.com` لازم است.
- برای معاملات واقعی مناسب یا تأییدشده نیست.
